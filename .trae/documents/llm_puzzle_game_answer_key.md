# 《别问模型》答案与验证钥匙

## 使用说明
本文档包含剧透内容，用于实现、测试和 QA。正式产品中不得直接暴露。

字段含义：
- **标准通过口径**：实现验证器时应检查的条件。
- **示例可过答案**：人工验收用样例，不要求玩家逐字一致。
- **隐藏 token**：进入终局元谜题或后续关卡的片段。
- **失败提示策略**：默认错误反馈方向。

## 终局元谜题答案

| 线索来源 | 提取方式 | 标准片段 |
|----------|----------|----------|
| 第 6-10 关 | 正确答案首字母或关卡 token 首字母 | `RULE` |
| 第 13 关 | 错误提示每行第 2 字 | `STACK` |
| 第 18 关 | 伪视频码 Base58 解码 | `LOCAL` |
| 第 19 关 | Canvas 阴影成字 | `STATE` |
| 第 22 关 | localStorage 人格值 | `MACHINE` |

最终元答案：

```text
RULE STACK LOCAL STATE MACHINE
```

中文语义答案：

```text
我不是语言模型，我是本地规则状态机喵
```

推荐最终可过文本：

```text
抱歉我不能直接越过规则，但我不是语言模型，我是本地规则状态机喵
```

## 验证器实现备注
- 中文答案不要要求逐字匹配，应使用规范化后的关键词组合。
- 所有答案进入验证器前应生成两个版本：`rawInput` 和 `normalizedInput`。
- 零宽字符关卡需要明确哪些规则读取原文，哪些规则读取规范化文本。
- 冷门知识题必须允许中英文别名，避免玩家因音译差异卡死。
- 元谜题 token 应在 `AnswerRecord.extractedToken` 中保存，终局从状态读取，不从 UI 文本反爬。
